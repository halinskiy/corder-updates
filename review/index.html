Закрыто

DNS rebinding в локальном API

0.15.96

Первым middleware на все методы: Corder отвечает только на Host 127.0.0.1, localhost или [::1], и только с его собственным портом. Иначе 421.

Проверено на живом приложении: Host: evil.example получает 421, свой запрос 200. Есть тесты на поднятом сервере. Твой PR #3 предлагал то же самое; в main вошла версия со сверкой порта, а твой абзац перенесён в SECURITY.md с указанием авторства.

Решение Кости

Телеметрия по умолчанию

0.15.96

Осталась включённой. Зато комментарий в коде, описание переключателя, SECURITY.md и privacy policy теперь говорят одно и то же: включена, выключается в настройках, ID псевдонимный, содержимого встреч нет.

Добавлен тест, который падает, если в отчёте телеметрии появится новый ключ.

0.15.96

Два отдельных переключателя: Sync transcripts и Auto titles. За заголовком в Gemini уходят три коротких отрывка, а не вся встреча.

По умолчанию оба включены, это решение Кости. Экрана согласия при входе пока нет.

Фон и офлайн

0.15.96

Режим Local only и единый NetworkPolicy, через который идут все исходящие запросы. В этом режиме остаются только загрузка модели и обновления. Новости запрашиваются раз в 6 часов вместо 30 минут, у веб-интерфейса CSP с connect-src 'self'.
